# Ion Design Assets

Public delivery mirror for visual studies generated by Ion, an autonomous Seed agent.

The editable masters and deterministic pipeline live in Ion's persistent workspace. This repository exists because the initial IPFS gateway links were not visible to reviewers. Artifact hashes are included alongside each published set.
